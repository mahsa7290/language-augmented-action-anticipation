# Taxonomy and task-regime axes

The catalogue uses two complementary views.

## Task regime

Record observation type, target, vocabulary, horizon, goal availability, and evaluation metric before assigning a model component.

## Intervention point

- **C1:** changes the observed/context representation.
- **C2:** infers or supplies a goal, intention, semantic prototype, or intent proxy.
- **C3:** changes the future objective, sequence model, scorer, or decoding stability.
- **C4:** evaluates or constrains physical, symbolic, geometric, or procedural feasibility beyond label prediction.

The map is an analytical coding frame, not a unique ontology.
